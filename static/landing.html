The Academic Chaos

University WhatsApp or Telegram groups are a mix of crucial study materials, casual chatter, and images of handwritten notes. Searching through this unstructured data is nearly impossible.

  • Handwritten notes shared as JPGs are unsearchable
  • Important PDFs (assignments, syllabus) get buried instantly
  • Context is lost across hundreds of messages

The NLP Solution

Upload a standard WhatsApp or Telegram `.zip` / `.html` or `.json` export. The backend parses the data, runs Optical Character Recognition (OCR) on images, extracts text from PDFs, and uses RAG for semantic search.

  • Images of notes become fully searchable text
  • LLMs classify documents by subject and type
  • Semantic Search (RAG) retrieves answers instantly

Core Engineering Features

Built strictly with production-ready AI and Data Processing pipelines.

Advanced OCR Pipeline

Integrated PyTesseract and Pillow to automatically extract text from images of handwritten notes and whiteboard snapshots shared in chat.

Multi-Format Parsing

Utilizes PyMuPDF, pdfplumber, python-docx, and python-pptx to aggressively extract raw text from any academic document format uploaded to the group.

RAG & Semantic Search

Vectorizes all extracted text using `sentence-transformers`, allowing users to ask natural language questions ("What did the professor say about Midterms?") and retrieve exact context.

Multi-LLM Integration

Built with an abstraction layer supporting Anthropic (Claude) and Groq. The LLMs are utilized for intelligent text chunk classification and summarization.

High-Performance API

Powered by FastAPI and Uvicorn. Utilizes asynchronous processing to handle heavy I/O operations like parsing large WhatsApp or Telegram exports and running ML inference.

Relational Integrity

Uses SQLAlchemy and PostgreSQL to maintain strict relationships between original messages, extracted files, vector embeddings, and their generated classifications.

Interactive Vault Chatbot

A built-in frontend interface that allows users to chat directly with their academic vault. Get instant answers backed by RAG context.

Technical Architecture

A breakdown of the backend processing pipeline.

1. Ingestion & API Layer

FastAPI handles multipart file uploads. The parser strips HTML/JSON from standard WhatsApp or Telegram exports to isolate individual messages, senders, and attached media.

FastAPI Uvicorn python-multipart

2. Document & OCR Processing

Attachments are routed to format-specific extractors. Images are passed through Tesseract OCR, while PDFs and Office documents are parsed via specialized libraries.

PyTesseract PyMuPDF python-docx

3. Embeddings & RAG Engine

Extracted text is chunked and embedded using open-source sentence-transformers, then stored for rapid semantic similarity search across the entire chat history.

sentence-transformers numpy RAG

4. LLM Classification

Anthropic Claude and Groq APIs analyze the context to automatically categorize files (e.g., Syllabus, Assignment) and flag important deadlines.

Anthropic API Groq API SQLAlchemy
